# Security Policy

## Reporting a Vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository, not in a
public issue. Include steps to reproduce, impact assessment, and proof-of-concept details. You will receive an initial response within three business days and a mitigation timeline within fourteen.

## Supported Versions

Only the latest release on the `main` branch is actively supported with security patches.

## How EventCraft Protects Users

Comprehensive security measures (strict input validation, Content Security Policy with Trusted Types, dual-tier rate limiting, credential scrubbing, and supply-chain pinning) are detailed in the [Security section of the README](README.md#3-security--safe-practices).
